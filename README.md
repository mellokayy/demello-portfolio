# Portfólio — Site Estático

Este repositório contém a versão **estática (HTML, CSS e JavaScript)** do meu portfólio.

O projeto foi originalmente desenvolvido em **WordPress** e posteriormente **exportado para um site estático**, com o objetivo de garantir melhor desempenho, simplicidade de hospedagem e compatibilidade com o **GitHub Pages**.

## 📦 Sobre o projeto
Este portfólio apresenta:
- Landing page institucional
- Seção de serviços
- Projetos demonstrativos
- Informações de contato

Após a finalização do layout e do conteúdo no WordPress, o site foi exportado para arquivos estáticos e publicado via **GitHub Pages**.
